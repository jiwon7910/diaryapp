# 📸 기록일지 - 폴라로이드 앨범 앱

갤럭시용 아기자기한 폴라로이드 스타일의 기록일지 앱입니다.

## ✨ 주요 기능

### 📱 메인 화면
- 폴라로이드 사진처럼 디자인된 앨범 카드들이 그리드로 표시됩니다
- 각 폴라로이드는 하나의 앨범 버튼 역할을 합니다
- 하단에는 필기체로 제목과 날짜/기간을 표시합니다
- 크림색 배경으로 감성적인 분위기를 연출합니다

### 📚 앨범 관리 (CRUD)
- **추가**: 오른쪽 하단 핑크색 FAB 버튼으로 새 앨범 생성
  - 커버 사진 선택
  - 제목, 날짜/기간, 메모 입력
- **조회**: 폴라로이드를 탭하면 해당 앨범으로 이동
- **수정**: 폴라로이드를 길게 누르면 수정 옵션 표시
- **삭제**: 길게 눌러서 삭제 가능 (확인 다이얼로그 표시)

### 📷 앨범 내부 (사진 관리)
- 각 앨범당 최대 20장의 사진 추가 가능
- 각 사진마다:
  - 이미지
  - 메모 (선택사항)
  - 날짜 (선택사항)
- 사진 길게 눌러서 삭제 가능
- 폴라로이드 스타일로 사진 표시

### 💾 데이터 저장
- SharedPreferences와 Gson을 사용한 로컬 데이터 저장
- 앱을 닫아도 모든 앨범과 사진이 유지됩니다

### 🔐 권한 관리
- Android 13+ : READ_MEDIA_IMAGES
- Android 12 이하 : READ_EXTERNAL_STORAGE
- 런타임 권한 요청 자동 처리

## 🎨 디자인 특징

- **폴라로이드 테마**: 하얀 테두리와 하단 여백이 있는 폴라로이드 스타일
- **감성적인 색상**:
  - 크림 배경 (#FFF8F0)
  - 폴라로이드 화이트 (#FFFEF9)
  - 액센트 핑크 (#FFB6C1)
  - 액센트 블루 (#B0E0E6)
  - 필기체 색상 (#5D4E37)
- **필기체 폰트**: 날짜와 메모에 사용되어 손글씨 느낌
- **그림자 효과**: 폴라로이드가 떠있는 듯한 입체감

## 🛠️ 기술 스택

- **언어**: Kotlin
- **최소 SDK**: 26 (Android 8.0)
- **타겟 SDK**: 36
- **UI**: 
  - ViewBinding
  - RecyclerView with GridLayoutManager
  - Material Design 3
  - CardView
- **데이터**:
  - Gson (JSON 직렬화)
  - SharedPreferences
- **이미지**: Android Photo Picker (ActivityResultContracts)

## 🚀 실행 방법

1. Android Studio에서 프로젝트 열기
2. Gradle 동기화 대기
3. 갤럭시 디바이스 또는 에뮬레이터에 연결
4. Run 버튼 클릭

## 📱 사용 방법

1. **첫 화면**: 오른쪽 하단의 + 버튼을 눌러 첫 번째 앨범 생성
2. **앨범 만들기**: 
   - 사진 선택 버튼으로 커버 이미지 선택
   - 제목과 날짜 입력 (예: "여름휴가", "2024.07")
   - 메모 추가 (선택사항)
3. **앨범 열기**: 폴라로이드 카드를 탭
4. **사진 추가**: 앨범 내부에서 + 버튼으로 사진 추가 (최대 20장)
5. **수정/삭제**: 폴라로이드나 사진을 길게 눌러서 옵션 메뉴 열기
